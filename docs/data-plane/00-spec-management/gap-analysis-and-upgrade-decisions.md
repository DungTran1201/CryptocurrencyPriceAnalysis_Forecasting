## 3. Phased Upgrade Roadmap

1. **Wave 0 — Foundations & Safety (`WI-DP-01`, `WI-DP-12`, `WI-DP-05`, `WI-DP-11`):** Lock Spec Pack (`docs/data-plane/`), enforce `TEST-ISO` isolation in `tests/conftest.py`, ship unified Alembic migration (`batch_ledger`, `lake_snapshots`, `lake_manifest_files`, `warehouse_snapshots`, `workflow_*`), unify `Settings`/`config.yaml`, pin deps + add `psycopg[binary]>=3.2.0,<4.0` (`postgresql+psycopg://` normalization).
2. **Wave 1 — Data Plane Core Reliability (`WI-DP-02`, `WI-DP-03`, `WI-DP-04`, `WI-DP-07`, `WI-DP-10`):** Fix consumer post-commit dedup/ACK state machine, producer spill & NATS `_conn_epoch`, immutable Lake + SQL manifests + `ON CONFLICT` promotion, durable SQL `WorkflowEngine`, and per-process observability.
3. **Wave 2 — Serving, Warehouse & Hardening (`WI-DP-06`, `WI-DP-08`, `WI-DP-09`, `WI-DP-13`):** Implement persistent DuckDB Star Schema + `dw-v{N}.duckdb` snapshots, `ServingGatewayBridge` + `HotStateCache` over NATS Core/KV, manifest-driven Governance/Retention (zero GET writes), and API auth/error sanitization + ML training offload.
4. **Wave 3 — UI Alignment, System Verification & Docs (`WI-DP-14`, `WI-DP-15`):** Update React views for `run_id` / `QUEUED` workflow contract, run full unit/integration/pipeline/system fault-injection (`S1–S14`) & resource profiling suites, and reconcile `README.md` + `docs/audit/codebase-audit.md`.
